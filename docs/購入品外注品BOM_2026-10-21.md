# 購入品・外注品のBOM登録

パーツ型のBOMは必要工程0件を許可。購入品・外注品など社内加工を行わないものも必要数量・名称・備考を保存できる。工程がないことは入荷や完了を意味せず、金型詳細の進捗とBOM対象工程欄は「社内加工なし」と表示する。

社内加工なしの項目はガント追加の選択肢を無効化し、送信時にも拒否。BOMのガント登録リンクも表示しない。加工工程・作業時間ゼロのダミータスクは作らない。入荷予定・発注・納品確認の管理機能は今回追加していない。

既存のプレート型の標準3工程必須ルールは維持。社内加工なしで登録する場合はパーツ型の区分を使用する。外注後に社内加工する項目は、その社内工程だけを選択する。

## DB適用

`supabase/migrations/202610210001_bom_no_internal_process.sql` をSupabase SQL Editorで実行する必要がある。空工程を拒否していたCHECK制約だけを変更し、プレート要件・工程カタログ・権限・監査・改訂番号処理は維持する。既存データの更新や削除は行わない。繰り返し実行可能。

ローカルDBテストで、工程あり→工程なし→工程ありの保存と取得を確認。入力検証テスト・型チェック・Lintも実施。実環境へのSQL適用は未実施。
