# ガントの金型名リンク

ガント左側の「金型 / パーツ / 工程」「設備 / 使用プレスNo」「担当」「加工順」の列見出しをなくし、「金型名」に集約。予定行の主表示も工程名から金型名へ変更した。金型名クリックで既存の金型詳細ページ `/workspace/products/:id`（デモでは `/demo/products/:id`）へ遷移する。

機械別の1行に複数金型がある場合は該当金型名をそれぞれリンク表示する。機械間ドラッグの移動先識別に必要な機械名は小さい補足表示として維持。担当・加工順・件数の独立表示は削除。予定一覧ボタンは維持。空き機械は「予定なし」と機械名を表示し、引き続きドロップを受け付ける。

バー表示・日程計算・DB保存には変更なし。編集中の未保存変更がある場合は既存の画面移動防止を維持。

確認：型チェック・Lint。リンク先は既存の金型詳細ページを使用。
