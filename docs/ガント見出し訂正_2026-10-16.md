# ガント見出し訂正

ユーザー訂正：金型名リンクへの行表示変更は不要だった。直前の変更を取り消し、各予定行の工程名、設備・使用プレスNo、担当、加工順、予定一覧と従来のレイアウトを復元。

左上の「金型 / パーツ / 工程」見出しだけを指定された「金型A」に置換。その他の見出し・予定計算・実績ガント表示は維持。金型名リンク追加と専用CSSは取り消した。直前の「ガント金型名リンク」文書より本訂正を優先する。

確認：型チェックとLint。

追加指示：左上の「金型A」は、登録済みの同名金型の詳細ページへのリンクにする。行内の他表示は元どおり維持。該当金型がないデモ等では、別の金型へ誤遷移しないよう文字のみ表示する。
