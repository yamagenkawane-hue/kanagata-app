# BOM区分管理の追加設計

## 承認済み要件
任意の区分名称を登録し、プレート型（名称リスト・全5工程）またはパーツ型（名称自由・必要工程選択）を指定する。BOM画面から区分管理へ移動し、作成した区分をBOM登録で選択する。

## 構成
bom_categoriesを追加し、BOM項目のcategory_idを参照する。既存のプレート・パーツの基本区分を作成して既存BOMを紐付ける。kindは従来の計算・プレート制限との互換用に残し、区分の型と一致させる。
管理者が区分を登録・編集・使用停止する。使用中の区分の型変更は禁止し、名称変更は許可する。停止区分は新規登録から除外し、既存BOMの編集では保持できる。プレート重複判定は型ベースなので区分名称を変えても回避できない。
業務read_planningとmanage_entityを互換ラッパーで拡張する。旧関数の直接実行は認証ロールに許可しない。更新は既存revision・監査ログ・権限制御を利用する。
画面は/workspace/bom-categories。デモは既存2区分で読取のみ。API /api/businessのmaster対象をcategoryへ拡張。
