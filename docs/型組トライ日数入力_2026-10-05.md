# 型組・トライの日数入力（2026-10-05）

## 要件・設計

Must: 予定作成と編集で型組・トライの所要時間を「所要日数（日）」に変更し、1日以上の整数のみ受け付ける。マシニング・自動研磨・ワイヤーは30分単位の分入力を維持する。

1日は勤務時間8:50～17:40から昼休み50分・午後休憩10分を引いた実働470分（7時間50分）。会社カレンダーの稼働時間を使い、休憩と休日を除いて配置し、後工程も従来の自動計算で調整する。途中の時刻から開始した場合は翌稼働日へ持ち越すため、日数は日付枠の数ではなく実働量を表す。

## 実装

- BOMからの予定登録、デモ予定登録、予定編集で整数日数を入力する。
- `src/domain/duration.ts`で日数を分に変換し、API・自動配置でも工程に応じた所要量を検証する。
- DBの既存`duration_minutes`列を使い、型組・トライのみ470分の倍数を許可する。新しいテーブルやAPIは追加しない。
- 旧予定の30分刻みの値は維持する。旧予定を編集すると日数入力へ切り替わるため、その旨と旧所要時間を画面に表示する。保存後は入力日数の所要量になり、日程変更の確認画面を経て確定する。
- 型組・トライの日数入力では休憩中稼働・夜間稼働を指定しない。実績の開始・終了時刻と作業時間の入力方式は維持する。

Supabase SQL Editorで`supabase/migrations/202610050003_task_days.sql`を実行する。既存タスクの値を変更せず、制約のみ変更する。未適用では470分などの新しい日数予定の保存に失敗する。実環境への適用は未確認。
