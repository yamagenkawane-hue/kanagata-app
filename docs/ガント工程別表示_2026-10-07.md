# ガントの工程別表示順

見た目と金型・パーツごとのまとまりを維持し、各まとまり内の工程を上からマシニング、自動研磨、ワイヤー、型組、トライの順に並べる。新しい工程見出しは追加しない。バーの名称は従来どおりパーツ名（金型単体工程では型組・トライ）を使用する。

メイン見出し「金型別 生産計画」、工程・機械詳細、絞り込み、予定と実績の編集は維持する。DBの取得順にかかわらず工程順で表示する。表示順のみの変更で、設備の加工順位・日程計算・DBには影響しない。追加SQLは不要。

LintとTypeScriptを含むビルドで確認する。

【次のAIへの引き継ぎ事項】
ガントの見た目を維持し、工程行の表示順を固定。表示順と設備の加工順位は別の設定である。
