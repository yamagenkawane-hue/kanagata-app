# 標準プレート一括BOM登録（2026-10-21）

## 要件・設計

新規金型に毎回同じプレートを個別登録する手間を減らす。BOM設定で金型と幅・長さを指定し「標準プレートを登録」を押すと、PB・PP・SB・SP・DB1・DPを各1枚登録する。DBは既存名称「DB1ダイバッキング」に対応する。数量1枚を初期値とし、登録後に編集可能。

必要工程はマシニング・自動研磨・ワイヤー。型組・トライ、DS1/DS2、DB2/DB3は追加しない。加工予定は既存のガント登録機能から作成する。

## 実装・操作

- 金型管理で新規金型を登録し、BOM設定の「標準プレートをまとめて登録」で選択する。
- 共通サイズを入力し登録。既存のプレート区分と名称候補を使用する。
- 同じ金型に登録済みの同名プレートは追加しない。6種類が揃っている場合は登録ボタンを無効にする。
- 不足分を追加する場合、入力サイズは金型の共通サイズとして既存の共通寸法対象にも反映する。個別指定の寸法は維持する。
- SBのサイズ・枚数は登録後に編集できる。共通寸法と個別指定は従来機能を使用する。
- 管理者のみ保存可能。API入力検証、DB権限・更新競合チェックを実施する。
- 全件を一つのDBトランザクションで保存し、途中エラーは全件ロールバックする。内部の既存保存処理を再利用するため、初回登録のrevisionは6増加する。

## DB適用

前回までのSQL適用後、Supabase SQL Editorで `supabase/migrations/202610210004_standard_plate_bom.sql` を1回実行する。既存BOMへ自動追加する移行処理は含めない。
