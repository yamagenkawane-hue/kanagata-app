## 業務ルールと実装

### 製品・パーツ

- 製品の項目: 製品名、取引先、納期、備考。
- パーツの項目: パーツ名、数量、図番。
- 必須: 製品名、納期、パーツ名、数量。その他は任意。
- 新しい製品とパーツを登録できる。
- 既存の製品へパーツを追加できる。既存製品の情報は追加画面で読み取り専用。
- 各パーツに5工程の設備・担当者・所要時間・夜間条件を設定する。
- 管理番号・金型名という独立した入力項目は設けていない。

### 生産計画とガント

- 製品・パーツごとに工程の行を表示し、設備、担当者、設備内順位を併記する。
- 1日、3日、1週間の表示切替と期間移動ができる。
- 基本グリッドは30分。1日表示では30分目盛りを表示し、広い期間では時刻のラベルを間引く。
- 製品名・パーツ名・取引先の検索、製品と設備の絞り込みを実装した。
- 工程別の色、状態、固定、夜間、設備重複の表示を実装した。
- 休日、勤務時間外、休憩を背景に表示する。
- 工程クリックで予定・実績の詳細パネルを開く。
- **最新変更: バーの文字を工程名からパーツ名へ変更した。** 例: 「パンチプレート」など、登録されたパーツ名を表示する。左側の行、凡例、詳細パネルには工程名を残す。
- バーのツールチップは製品名・パーツ名・工程名・開始終了・状態を表示する。
- 現在の表示構造はパーツ配下の工程行であり、設備を親にしたガントへの再構成は実施していない。

### 日程の自動計算

固定順序は「マシニング → 自動研磨 → ワイヤー → 型組 → トライ」。省略・繰り返し・順序変更は扱わない。

- 所要時間は30分刻み、開始・終了は1分単位で扱う。
- 通常の勤務時間は8:50〜17:40。
- 昼休みは12:00〜12:50、休憩は15:00〜15:10。通常の実働は1日470分。
- 会社カレンダーの稼働日を使って計算する。必要な日が未設定ならエラーを返す。
- マシニング・自動研磨・ワイヤーは、タスクごとの夜間指定で休憩・夜間・休日を含む連続稼働を許可する。
- 通常タスクにも休憩中の設備稼働指定を用意した。
- 設備内の未着手タスクを1・2・3…で並べる。途中に挿入すると後ろの順位を振り直す。
- 飛び込み登録は挿入順位を指定でき、各工程の設備にその順位で挿入する。
- 前工程の終了、開始可能日時、設備内の順序と空き時間から後工程を計算する。
- 設備の重複を避けるため、空いている時間へ予定をずらす。
- 作業中・完了済み・固定した予定は自動調整の対象から外す。
- 指定開始による手動配置も用意し、設備の重複がある場合は管理者の確認を要求する。
- 日程の変更案は確定前に変更前後と納期超過を表示する。
- 管理者のみが変更案を確定できる。プレビュー後にデータが変わった場合は古い案を確定しない。
- 固定予定との矛盾、順序の循環、所要時間不正などはエラーで通知する。

### 実績

- 状態は未着手・作業中・完了。進捗率は使用しない。
- 作業開始・終了から休憩を控除した作業時間を計算する。
- 必要に応じて作業時間を手動修正でき、修正理由は任意。
- 担当者は別の担当者の実績も登録・修正できる。
- 実際の作業者と編集者を記録する。
- 実績ごとに当時の休憩設定を保持する。
- 日付をまたぐ作業時間を日別に分ける計算関数を用意した。
- 実績の時間重複は警告と確認後に保存できる。
- 実績保存後に残りの予定を再計算する。実績自体の時刻は移動しない。
- 実績保存と予定確定は分離する。担当者の実績入力後も、日程の確定は管理者が行う。
- 人の作業時間と設備の無人稼働時間は別のものとして扱う。

### マスターとデモ権限

設備・担当者一覧と、会社カレンダーの稼働日変更画面を用意した。
設備名・担当者名と初期休日は架空のデモデータ。設備・担当者マスターの本番CRUDは未実装。
画面内の管理者／担当者切替はデモ操作用で、本番のログイン権限を代替しない。
