# プレートサイズと概算による予定自動登録

## 要件・計算ルール

幅・長さをmmでBOMプレートへ登録。縦横を入れ替えても長辺で同じ判定にする。初期値は機械1台につきマシニング240分／枚、自動研磨は長辺300mm以下240分／枚、300mm超480分／枚、ワイヤー480分／枚。1日8時間換算の概算値で、1日の登録枚数を強制制限する機能ではない。従来どおり開始後は所要時間分を連続加工する。

BOM設定の「プレートの概算加工時間を設定」で各時間とサイズ境界を変更できる。時間は30分単位。設定変更だけでは登録済み日程を再計算・更新しない。

## 操作

1. 追加SQLを実行する。
2. BOM項目の編集でプレートの幅・長さを登録する。既存BOMのサイズは自動で仮入力しない。
3. 必要ならBOM設定で概算時間を変更する。
4. ダッシュボードの「プレート予定を自動登録」で金型・開始可能日時・担当者を選ぶ。
5. 未登録数量のプレートを1枚ずつロット登録し、工程順と機械の予定を考慮して、試算した終了が最も早い有効機械に割り当てる。
6. 変更案と納期超過を確認し、既存の確認画面で確定してDBに保存する。確認前はDBへ予定を保存しない。

通常の「BOMから予定を追加」でもサイズのあるプレートは、選択数量分の概算時間を所要時間へ初期入力する。個別の手修正は可能。個別登録はサイズなしでも手動で時間を指定できるが、一括自動登録はサイズ不足をエラーとする。

## 制約と保存

- 一括自動登録は未登録のプレートだけが対象。部品、購入品・外注品、型組・トライは対象外。予備用の用途分割は別の未実装要件。
- 1回100枚、既存を含め2000ロットが上限。分割・機械間並行配置により1枚完了後に次工程へ進める。
- 追加工程の概算は未設定なので、自動登録ではエラーを表示し個別登録を案内する。標準工程を勝手に省略しない。
- 開始は既存の30分単位・会社カレンダー・勤務時間を使用。「勤務時間外・休日の加工開始を許可」を選ぶと連続開始可能。
- 既存の完了・作業中・固定予定を維持。未着手は元の予定より前へ戻さない開始条件を置いて再計算する。計算は候補データ上で行い、失敗しても部分的に保存しない。
- 保存は既存の改訂番号チェックとcommit_planを使い、競合時に自動連打しない。
- 実績による自動推定は将来対応。新規ロット作成時のプレートサイズをスナップショット保存し、後からBOMサイズを直しても加工時の寸法を残す。旧ロットの不明サイズを推測で補完しない。

## 設計・DB

`src/domain/estimates.ts` が概算計算と自動配置を担当。設定値は `estimate_settings`、現行サイズは `bom_items.width_mm/length_mm`、新規ロットの履歴サイズは `parts.plate_width_mm/plate_length_mm` に保存。

`supabase/migrations/202610210002_plate_estimates.sql` をSupabase SQL Editorで1回適用する。既存データの削除・既存予定の一括上書きはない。管理者だけが設定・サイズを保存可能。RLSと既存の権限・監査・改訂競合の処理を維持し、read_planningの取得値へ設定と寸法を追加する。APIはSQL未適用時に保存エラーを明示し、寸法の保存漏れを防ぐ。

## 引き継ぎ

SQL適用後に、実際のBOMプレート寸法を入力して自動登録を利用できる。実績推定へ切り替える条件・最低件数・算出方法は未確定で、今回の概算機能に混在させない。
