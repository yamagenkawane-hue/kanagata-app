# 金型詳細と管理画面の見方

ガントまたは金型管理で金型名をクリックすると、会社名、納期、型組・トライの開始予定が表示されます。中央の表では、プレート・パーツごとに必要数量と工程別の進捗を横に読みます。BOMの名称を開くと寸法、区分、登録数量、備考を確認できます。

作業中は青、完了は水色、未着手は黄色です。「予定未登録」は対象工程の予定がまだないこと、「対象外」はその部品でその工程を使わないことを示します。購入品など社内加工を指定していない項目には「社内加工なし」と表示します。

| 画面 | 確認・操作 |
| --- | --- |
| 金型管理 | カードで取引先と納期を確認し、金型名から詳細に移動 |
| BOM設定 | 必要数量、予定登録済み、未登録を列別に確認 |
| 工程管理 | 設備名から加工予定・加工順を開く。停止中の設備は一覧上部で表示切替 |
| BOM名称リスト・ユーザー設定 | 利用可否を「有効」「停止」の文字と色で確認 |
| 会社カレンダー | 表示月を選び、稼働日とピンクの休日を確認。「すべての月」で全登録日を表示 |
| 作業実績 | 記録時間の下の「日別の内訳」で日ごとの自動計算を確認 |
| 運用確認 | 「確認済み」「注意」「要対応」を色と文字で確認 |
