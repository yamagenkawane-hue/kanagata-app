# デモ管理者ログイン

ID admin・パスワード admin の指定で、ログイン画面から管理者モードの `/demo` に進める。これは公開デモへの入口であり、実Supabaseのアカウント・認証Cookie・DB権限は作成しない。実DBへのユーザー登録を行ったという意味ではない。

デモ入口はSupabase未設定でも利用できる。ログイン画面に指定の組合せとデモであることを表示する。デモ変更は従来どおりブラウザのメモリ内で、再読み込みすると消える。

その他の入力は従来のSupabaseログイン処理へ進む。通常アカウントの登録条件は8文字以上を維持し、別のパスワードで登録済みのadminアカウントの実データログインも妨げない。sameOrigin、入力形式・サイズ検証を通した後にデモを判定する。

検証：全63件のテスト・Lint・Webpack本番ビルド成功。指定の組合せ、IDの正規化、パスワードの厳密一致、通常アカウント条件の維持を確認。ローカル本番サーバーでデモログインHTTP200・demo=true、デモ画面HTTP200、Supabase認証Cookie未発行、外部OriginのHTTP403を確認。ブラウザでの入力・遷移操作は未確認。
