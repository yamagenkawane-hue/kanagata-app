# 要件ヒアリングメモ

更新日: 2026-09-30
状態: requirements（ヒアリング中。要件定義書の確定・承認前）

## 確認済みの要望

- 生産管理システムをNext.jsで開発する。
- 提示画像を参考に、一覧とガントチャートを組み合わせた画面を作る。
- 管理する工程: マシニング、自動研磨、ワイヤー、型組、トライ。
- 管理対象: 工程、進捗、担当者。
- ガントチャートは日ごとの表示を希望。細かいパーツごとのタスクと終了予定時刻を確認できること。時間の最小単位は30分。
- 通常勤務: 8:50〜17:40。昼休み: 12:00〜12:50。休憩: 15:00〜15:10。
- 上記から算出する通常勤務の実働時間: 1日7時間50分（530分から休憩60分を除く）。
- 管理番号と金型名は登録項目に不要。製品名を使用する。
- 進捗率（％）は不要。作業時間は必要。
- 設備ごとに予定を管理する。
- 稼働日と休日は、会社カレンダーですべて設定する。固定の土日休みや祝日休みは前提にしない。
- マシニング、自動研磨、ワイヤーは夜間稼働する場合がある。
- 夜間稼働は管理者がタスクごとに設定し、翌朝まで日付をまたぐ予定を登録できる。
- 休憩中も設備を動かせる。
- 登録項目: 製品名・パーツ名・数量・図番・顧客名・納期・備考。
- 同じ設備で予定が重複した場合は警告し、管理者が確認すると保存できる。
- 重複する予定に優先順位を設定できること。
- 優先順位は1・2・3…の数値で実行順を指定する。
- 飛び込みタスクを順番の途中に挿入できる。
- 飛び込み挿入・順番変更に応じて、後工程の日程を自動調整する。
- 自動調整は未着手タスクのみ対象。作業中・完了済みと実績は維持する。
- 変更後の日程と納期超過を管理者が確認してから保存する。
- 工程担当者は他の担当者の実績も入力・修正できる。
- 実績は作業開始・終了時刻を入力し、休憩を除いた作業時間を自動計算する。必要に応じて計算結果を修正できる。
- 工程ごとの所要時間から、固定順の5工程の日程を自動計算する。
- 自動計算は、設備の予定重複を優先順位に従って空き時間へずらして回避する。
- 管理者は自動計算後に手動変更でき、重複警告を確認した上で重複予定も保存できる。
- 所要時間は設備・工程の稼働時間として扱い、通常は勤務時間と会社カレンダー内で計算する。
- 夜間稼働指定のマシニング・自動研磨・ワイヤーは休憩・夜間・会社休日も継続可能。
- 工程の省略・繰り返し・順序変更はない。
- 工程順: マシニング → 自動研磨 → ワイヤー → 型組 → トライ。
- 想定利用人数: 約10名。
- 予定は管理者が作成する。
- 実績は工程担当者が入力する。
- 実績の入力項目: 状態（未着手・作業中・完了）、実際の開始日・完了日、日ごとの作業時間。
- 使用端末: PCのみ。

## 確認中（実装前に確定する項目）

- 登録項目の必須・任意の区分。
- 実績時間の修正時の理由入力と変更履歴の扱い。
- 30分単位の予定に加え、始業・終業・休憩境界の時刻を指定できる扱いの確認。
- 夜間の稼働可能時間帯の制限。
- 手動で重複保存した予定を、次回の自動調整で維持するか。
- 同じ設備の後続タスクと依存する後工程への変更伝播、同順位の扱い、変更プレビューの保存方法。
- 休憩中の設備稼働の指定方法（夜間指定がないタスクでも設備は休憩中に動かせる）。
- 個別メールアドレス・パスワードのログイン、全員の予定閲覧、管理者の予定・実績・会社カレンダー編集権限（提案中）。

## 後続の確認事項

- 全員の予定閲覧範囲。担当者の実績編集は本人分に限定しない。
- 同じ担当者に予定が重なる場合の扱い。
- 担当者の作業時間と設備の稼働時間の区別。夜間作業を行う担当者の実績入力の扱い。
- ガントチャートの表示期間と、予定・実績の表示方法。
- 既存データの移行、公開先、Supabaseプロジェクト。

## 画面・操作の提案（未承認）

- 製品 → パーツ → 固定の5工程のタスクという構成。
- 左に製品・パーツ情報、設備・担当者、右に工程を色分けしたガントチャート。
- 日付見出しの下で時間を区切り、パーツごとのタスクの開始・終了予定時刻を表示。
- 通常の予定操作は30分単位とし、8:50・17:40および休憩境界は別途指定可能にする（未承認）。
- 上部に表示期間切り替え、絞り込み、案件追加。
- 工程クリックによる詳細・編集と、ドラッグによる予定日時変更。
- 担当者の作業時間と設備の稼働時間を分け、無人稼働は担当者の作業実績に含めない。
- 優先順位をガント上で確認できる表示。
- 同じ設備の未着手タスクを順番に並べ、飛び込み挿入後は順番を振り直す。
- 自動調整は同じ設備の後続タスクと、それに依存する他の設備の後工程へ伝播する。
- 作業中・完了済みは維持し、未着手のみ自動調整する。
- 変更前後の日程と納期超過を表示し、管理者の確認後にまとめて保存する。
- 最初の開始日時と各工程の所要時間・設備・担当者を設定し、5工程の予定を計算する。
- 自動計算後も管理者が予定を調整できる。

画像内の品番・製品・工程名・メモ機能は参考情報であり、実際の要件として確定していない。
在庫・購買・原価管理は現時点で要求されていない。
